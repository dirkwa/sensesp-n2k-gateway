# Contributing

Bug reports, feature requests and pull requests are welcome at
<https://github.com/dirkwa/sensesp-n2k-gateway>.

Before opening a pull request, make sure the examples still build:

```bash
pio run -d examples/basic_gateway
pio run -d examples/gateway_plus_ble
```
